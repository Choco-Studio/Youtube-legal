Política de privacidad

Última actualización: 26 de octubre de 2026.

Datos a los que accede

  • Acceso a su cuenta de YouTube mediante OAuth 2.0, solo con el permiso necesario para subir vídeos a su propio canal.
  • Los vídeos, títulos y descripciones que el propietario decide publicar.
  • Datos públicos de YouTube consultados con una clave de API.

Cómo se usan

Los datos se usan únicamente para publicar contenido en el canal del propietario. No se venden, no se comparten con terceros y no se usan para publicidad.

Almacenamiento

Los tokens de acceso se guardan de forma privada en el equipo o servicio del propietario. Los vídeos no se conservan una vez publicados.

API de YouTube

Extensiones usa los servicios de la API de YouTube y cumple las Condiciones del Servicio de YouTube y la Política de Privacidad de Google. El uso de la información recibida de las API de Google cumple la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Revocar el acceso

Puedes retirar el acceso en myaccount.google.com/permissions. Para pedir la eliminación de datos, escribe a chocolabs.py@gmail.com.
